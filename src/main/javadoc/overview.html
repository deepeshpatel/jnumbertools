JNumberTools Overview

JNumberTools is a Java library for generating and working with combinatorial structures. Its public API covers permutations, derangements, combinations, subsets, Cartesian products, combinatorial ranking and unranking, and combinatorial number systems. Counts and ranks use BigInteger where the size of the combinatorial space can exceed primitive integer ranges.

Start with the static entry points on io.github.deepeshpatel.jnumbertools.base.JNumberTools. Select the structure and its parameters through the returned builder, then choose an enumeration or sampling operation. This is the intended public usage; implementation classes in generator subpackages are not the normal entry points.

Capabilities

  • Unique, repetitive, multiset and k-permutations; derangements.
  • Unique, repetitive and multiset combinations; subsets.
  • Simple and constrained Cartesian products.
  • Lexicographical enumeration, every-mth traversal where supported, and access by zero-based ranks.
  • Random selection with replacement (choice) and without replacement (sample).
  • Ranking, unranking, and BigInteger-based combinatorial counts and ranks.
  • Factoradic, Combinadic, Permutadic and Derangadic representations.

Package structure

PackagePurpose
basePublic entry points, structure-specific facades, Calculator, and rank/unrank APIs.
generator.baseShared builder and iterable contracts used by generator implementations.
generator.permutationPermutation and derangement generation strategies.
generator.combinationUnique, repetitive and multiset combination generation.
generator.subsetSubset generation, including size-restricted subsets.
generator.productSimple and constrained Cartesian-product generation.

Usage examples

All unique permutations

JNumberTools.permutations()
    .unique("A", "B", "C")
    .lexOrder()
    .forEach(System.out::println);

Every fifth unique permutation, starting at zero-based rank two

JNumberTools.permutations()
    .unique("A", "B", "C", "D")
    .lexOrderMth(5, 2)
    .forEach(System.out::println);

Combinations and subsets

JNumberTools.combinations()
    .unique(2, "A", "B", "C", "D")
    .lexOrder()
    .forEach(System.out::println);

JNumberTools.subsets()
    .of("A", "B", "C")
    .inRange(1, 2)
    .lexOrder()
    .forEach(System.out::println);

Ranking and unranking

BigInteger rank = JNumberTools.rankOf()
    .permutation()
    .unique(2, 0, 1);

int[] permutation = JNumberTools.unrankOf()
    .permutation()
    .unique(BigInteger.valueOf(4), 3);

Cartesian product

JNumberTools.cartesianProduct()
    .simpleProductOf("A", "B")
    .and("X", "Y")
    .lexOrder()
    .forEach(System.out::println);
