JNumberTools Overview

JNumberTools is a Java library for generating and working with combinatorial structures. Its public API covers permutations, derangements, combinations, subsets, Cartesian products, combinatorial ranking and unranking, and combinatorial number systems. Counts and ranks use BigInteger where the combinatorial space can exceed primitive integer ranges.

Start with the static entry points in io.github.deepeshpatel.jnumbertools.entrypoint: Permutation, Combination, Subset, Derangement, Product, Rank and Unrank. These return or create the appropriate builders. Builder classes live in io.github.deepeshpatel.jnumbertools.builders; Calculator and supporting data structures live in io.github.deepeshpatel.jnumbertools.datastructure.

Capabilities

  • Unique, repetitive, multiset and k-permutations; derangements.
  • Unique, repetitive and multiset combinations; subsets.
  • Simple, constrained, pairwise-conditional and lambda-predicate Cartesian products.
  • Lexicographical enumeration, every-mth traversal where supported, and access by zero-based ranks.
  • Random selection with replacement (choice) and without replacement (sample).
  • Ranking, unranking, and BigInteger-based combinatorial counts and ranks.
  • Factoradic, Combinadic, Permutadic and Derangadic representations.

Usage examples

Permutations, combinations and subsets

Permutation.unique("A", "B", "C").lexOrder();
Combination.unique(2, "A", "B", "C", "D").lexOrder();
Subset.of("A", "B", "C").inRange(1, 2).lexOrder();

Ranking and unranking

BigInteger rank = Rank.permutation().unique(2, 0, 1);
int[] permutation = Unrank.permutation().unique(rank, 3);

Cartesian product

Product.simple(List.of("A", "B"), List.of("X", "Y")).lexOrder();
